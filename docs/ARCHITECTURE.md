# NegoZaar — System Architecture & Production Blueprint

**Product Category**: B2B SaaS AI Negotiation & Conversion Layer for E-Commerce Merchants  
**Target Platforms**: Shopify (Initial), WooCommerce / BigCommerce / Custom Headless (Future)  
**Version**: 0.1.0 (Phase 1 Foundation)

## 1. Executive Summary & Product Boundary

NegoZaar is **NOT** an e-commerce storefront, marketplace, or standalone shopping website. Merchants already own and operate their e-commerce storefronts. NegoZaar is a multi-tenant B2B SaaS platform that provides an intelligent, AI-powered price negotiation layer on top of the merchant's store.

## 2. Core Architectural Pillars

### 2.1. Deterministic Pricing Guard (The Inviolable Law)
- **Principle**: The AI model is strictly treated as an **untrusted advisor**.
- **Enforcement**:
  1. The merchant defines a `min_acceptable_price` (floor price) and `max_discount_percentage`.
  2. Every proposal generated by an LLM is intercepted server-side by the `PricingGuard` before persistence or transmission.
  3. If an LLM hallucinates, attempts to give away a product for ₹1, or succumbs to prompt injection, the Guard clamps the price to the acceptable floor or triggers an invariant rejection.
  4. **Zero Floor Leakage**: The merchant's floor price is never passed to the client browser and is scrubbed from customer-facing conversational messages.

### 2.2. Multi-Tenant Isolation
- Tenancy is rooted at the `merchants` organization level.
- Merchants own one or more `stores`.
- Row-Level Security (RLS) policies in PostgreSQL strictly isolate merchant data.
- Tenant context is resolved via authenticated Supabase JWT sessions on protected routes.
- Storefront shoppers only communicate via temporary, cryptographically signed session tokens (HMAC-SHA256).

### 2.3. Clean Domain Separation
- **E-Commerce Platform Responsibilities**: Product catalog, cart management, checkout URLs, payment processing, fulfillment, and order placement.
- **NegoZaar Responsibilities**: Price negotiation logic, round governance, behavioral concessions, coupon claim issuance, and conversion attribution.

## 3. Detailed Component Architecture

### 3.1. Embedded Widget SDK & Storefront Gateway
- **SDK Bundle**: `public/sdk/negozaar.js` (Lightweight vanilla JavaScript, ~4KB).
- **Embed Mechanism**: Injected via Shopify Theme App Extension or `<script>` tag in `theme.liquid`.
- **Isolation**: Renders an iframe pointing to `/embed/widget`, preventing CSS conflicts with the merchant's theme.
- **Communication**: Uses window `postMessage` protocol to dispatch `NEGOZAAR_DEAL_ACCEPTED` events for instant checkout redirection.

### 3.2. Negotiation State Machine
Sessions transition through strict sequential states:
```
[INITIALIZED] ──► [ACTIVE] ──► [COUNTERED] ──► [ACCEPTED] (Terminal)
                    │               │      ──► [REJECTED] (Terminal)
                    ▼               ▼
               [EXPIRED]      [TERMINATED]
```
- **Turn-Taking**: Strictly alternating rounds between customer proposal and AI counter-offer.
- **Round Enforcement**: Configurable (default 3 rounds). Final round triggers a strict "take-it-or-leave-it" posture.

### 3.3. AI Abstraction Layer
- Interface: `INegotiationAIService`.
- Supported Providers:
  - `mock`: Offline deterministic provider replicating the exact benchmark negotiation curve (Round 1: ₹1,750, Round 2: ₹1,650, Final: ₹1,600).
  - `openai`: Structured JSON completions via `gpt-4o-mini`.
  - `gemini`: Native JSON response schema via `gemini-1.5-flash`.
- **Prompt Compiler**: Synthesizes negotiation state, recommended counter target, and brand voice without leaking secret floor limits.

### 3.4. Shopify Integration Adapter
- Interface: `IEcommercePlatformAdapter`.
- **Coupon Generation**: Calls Shopify PriceRule API to create a unique, single-use, time-limited discount code upon deal acceptance.
- **Checkout Link**: Generates deep-link `https://{shop}/discount/{code}?redirect=/checkout`.
- **Webhook Attribution**: Listens to `orders/create` with HMAC verification to attribute revenue to negotiation sessions.

## 5. Security & Threat Mitigation

| Threat Vector | Mitigation Strategy |
|---|---|
| **Prompt Injection / Jailbreak** | `SecuritySanitizer` neutralizes delimiter overrides; `PricingGuard` deterministically enforces floor limits regardless of LLM output. |
| **Floor Price Scraping** | Floor prices never enter client payloads, public APIs, or prompt output streams. |
| **Session Token Tampering** | Tokens are signed using HMAC-SHA256 (`alg: HS256`) with timing-safe equality verification. |
| **API Abuse / DoS** | Sliding window `RateLimiter` restricts public widget initialization and offer proposal frequency. |
| **Webhook Spoofing** | Shopify HMAC-SHA256 header verified in constant time before processing order events. |
